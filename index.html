Property alerts.
A little more order.

Hausbot helps its owner follow a house search along the Südbahn corridor south of Vienna. It brings relevant property information from Gmail into a private Telegram review workflow.

How Hausbot works ↓

Personal use · Read-only Gmail access · No public registration

The information’s journey

  1. 01

    Gmail

    Property links and listing information from messages in the connected mailbox.

  2. 02

    Hausbot

    A private service extracts listing details, checks the configured locations and records processing state.

  3. 03

    Telegram

    Matching alerts arrive in the owner’s review chat. Selected listings can be forwarded to the results channel.

The owner makes the decisions. Hausbot does not contact sellers or purchase property.

From alert to review

A simple, personal workflow.

1 / Collect

Read property information

Gmail mailbox notifications wake the private Cloud Run service. Hausbot reads message history and message contents to find supported Austrian property links and listing details.

2 / Filter

Keep location-relevant listings

A configured list of towns and postcodes limits alerts to the owner’s search area. Available facts such as price, living area, location and source link are kept for review.

3 / Choose

Review in Telegram

The owner reviews matching listings in the configured Telegram chat. A save command such as #ID vormerken forwards a selected listing to the configured results channel.

Why Google access is requested

Read-only access, with a clear purpose.

Hausbot requests the gmail.readonly permission. This lets the service read Gmail messages, not send email, delete mail or change its read/unread state. The permission covers the mailbox; incremental Inbox processing may retrieve messages beyond the intended portal alerts.

Extracted listing information and email-derived descriptions can be stored and sent to the configured Telegram destinations. AI assessment is not used in the current processing flow.
