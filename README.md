# Hausbot public information site

Public static homepage, privacy policy and terms for the personal-use Hausbot application.
Published on GitHub Pages at https://stezido.github.io/.

Only public site content belongs in this repository. The application source,
mailbox content, database, OAuth credentials and browser profiles are private and
must never be copied here. There is no runtime backend, credential collection,
analytics script or dependency installation.

## Preview

```sh
python3 -m http.server 5194 --bind 127.0.0.1
```

GitHub Pages uses the main branch repository root with Jekyll disabled. Keep
Google Search Console verification files/tags when changing the homepage.

## Data statements

Policy text was checked against the private application's current processing
flow on 2026-11-07: read-only Gmail access; full raw message retrieval during
Inbox history processing; persisted email-derived listing snippets; Telegram
review/forwarding; no active AI assessment. Revisit the policy before changing
those data uses. Statements are not a claim of Google approval.
